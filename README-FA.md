# ماشین حساب My Digi برای اندروید

این پروژه فقط **بخش ماشین حساب** فایل My Digi ارسالی شما را به برنامهٔ اندروید تبدیل می‌کند. محاسبات قیمت‌گذاری، دریافتی فروشنده، رقابت با فروشنده، حالت نقدی/اعتباری و جزئیات کسورات از همان `digicalc.html` گرفته شده‌اند. برنامه آفلاین است و اینترنت یا ورود به پنل نمی‌خواهد. تنظیمات هزینه‌ها روی همان گوشی ذخیره می‌شوند و به برنامهٔ ویندوز منتقل نمی‌شوند.

## ساخت APK روی کامپیوتر

1. [Android Studio](https://developer.android.com/studio) را نصب کنید. کل پوشهٔ `MyDigiAndroid` را با گزینهٔ **Open** باز کنید.
2. هنگام درخواست Android Studio، نصب SDK 35 و همگام‌سازی Gradle را انجام دهید. پروژه به JDK 17 و Gradle 8.9 نیاز دارد. این بسته Gradle Wrapper ندارد؛ Gradle 8.9 را نصب و در بخش **Settings → Build, Execution, Deployment → Build Tools → Gradle → Use local Gradle distribution** انتخاب کنید.
3. از **Build → Build Bundle(s) / APK(s) → Build APK(s)** استفاده کنید.
4. فایل خروجی `app/build/outputs/apk/debug/app-debug.apk` را به گوشی منتقل و نصب کنید. اگر گوشی اجازهٔ نصب از این منبع خواست، برای همان برنامهٔ مدیریت فایل اجازه دهید.

این بسته **فایل APK آماده نیست**؛ در محیط ساخت این پروژه Android SDK/Gradle نصب نبود و APK در اینجا کامپایل و روی گوشی آزمایش نشد.

اگر کامپیوترتان Android Studio ندارد، فایل‌های داخل این پوشه را در ریشهٔ یک مخزن GitHub بگذارید و از برگهٔ **Actions**، گردش‌کار **Build Android APK** را اجرا کنید. پس از اتمام موفق، فایل APK از بخش **Artifacts** همان اجرا قابل دریافت است. این مسیر نیز در این محیط اجرا و آزمایش نشده است.

ورودی‌های برنامه به تومان هستند. تنظیمات پیش‌فرض از ماشین‌حساب ویندوز همان فایل ارسالی برداشته شده‌اند: لیبل ۶٬۰۰۰؛ کف مجموع پردازش و ارسال ۳۶٬۰۰۰؛ سقف ۲۴۰٬۰۰۰؛ درصد مجموع ۷ و مالیات خدمات ۱۰. تنظیمات قبلیِ روی کامپیوتر خودکار به گوشی منتقل نمی‌شوند.
